Tutorial: logistics with JSON and many partners

MyCompany is a carrier: it moves loads by truck for shippers. Shippers send load tenders as X12 204; the transport management system (TMS) of MyCompany reads and writes JSON. In this tutorial you build the whole exchange for three shippers: 204 in, JSON tender to the TMS, 997 back; then the answer of the TMS (990, accept or decline) and its freight invoice (210) back to the right shipper. You build it so that the tenth shipper costs you minutes, not a new set of mappings.

In plain words

A shipper asks "can you move this load?" with a 204. Bots turns it into a JSON file that the TMS understands and tells the shipper "file received" with a 997. Dispatch decides in the TMS; Bots turns that decision into a 990 for the shipper. After delivery the TMS bills the load; Bots turns the bill into a 210. All shippers share the same mappings; where one shipper wants something different, a setting in Bots (a partner field, a code list entry, a small extra mapping) makes the difference.

What you will build

The business. MyCompany (X12 ID MYCOMPANY, carrier code SCAC MYCO) gets load tenders from three shippers: ShipperA, ShipperB and ShipperC (IDs SHIPPERA, SHIPPERB, SHIPPERC). A tender says what to pick up where and when, and where to deliver it (the stops). Every shipper sends X12 version 004010.

Note

The X12 grammars on this page are cut down for the tutorial: only the segments the example uses, and each segment only up to the last element used here. They follow the X12 004010 standard for what they contain, but a real 204 from a shipper often has more (MS3, PLD, LAD, N7 details…). For production use complete grammars (for example from the plugins on the Bots website) and check them against the implementation guide of each shipper. See X12.

Part 1: Partners, a partner group and partner fields

Every shipper is a partner. The group SHIPPERS says "these are our shippers": the translation of the 204 and the route to the TMS use the group, so a new shipper only has to be added to the group. Two free partner fields hold the differences that are only a value:

  • attr1: the weight unit the shipper wants on the 210: L (pounds) or K (kilograms).
  • attr2: auto if the shipper gets an automatic 990 (accept) as soon as the 204 arrives.
  1. Add the group. Configuration → Partnergroups → Add: tick Active, Partner identification SHIPPERS, Name Shippers. Save.
  2. Add your own company. Configuration → Partners → Add: Active, MYCOMPANY, MyCompany. Save.
  3. Add the shippers in the same way, and for each open Is in groups (move SHIPPERS to the right list) and User defined (attr1, attr2):

Watch out

The partner ID must be exactly the ID in ISA06 of the shipper's files (without the trailing spaces): Bots takes the sender of a 204 from ISA06 (see the envelope grammar in Part 2). A shipper that sends SHIPPERA1 instead of SHIPPERA is a different partner to Bots.

Part 2: The X12 grammars

Bots needs the envelope (x12.py), the segments (records004010.py) and one grammar per message. Bots finds the grammar of a received message from ST01 and GS08: 204 + 004010 = 204004010.py.

Part 4: The 204 mapping: stops, dates, references, weights

One mapping serves all shippers. It is the largest piece of this tutorial, so read it with the 204 of ShipperA (in Run it end to end) next to it.

  1. Write usersys/mappings/x12/loadtender_x12_to_json.py: 
    """Load tender: X12 204 from a shipper -> JSON load tender for the TMS of MyCompany.

Used for all shippers (translation with frompartner = group SHIPPERS).
A shipper that needs something different gets its own small mapping that
calls build_tender() and adds what is different.
"""
import decimal

import bots.transform as tr
from bots.botslib import MappingFormatError

LB_PER_KG = decimal.Decimal('2.20462')
PICKUP = ('LD', 'CL', 'PL')          # S502: load, complete load, partial load
DELIVERY = ('UL', 'CU', 'PU')        # S502: unload, complete unload, partial unload
PURPOSE = {'00': 'new', '01': 'cancel', '04': 'change'}
# N711 equipment type + N715 length -> equipment code of the TMS
EQUIPMENT = {
    ('TV', '5300'): 'VAN53',
    ('TV', '4800'): 'VAN48',
    ('RT', '5300'): 'REEFER53',
    ('FT', '4800'): 'FLAT48',
}


def put_values(node, *path, **fields):
    """Put only the fields that have a value.
    (If one value in a put is None, Bots writes nothing at all of that put.)"""
    values = {key: value for key, value in fields.items() if value is not None and value != ''}
    if values:
        node.put(*path[:-1], dict(path[-1], **values))


def pounds(weight, unit):
    """Weight in whole pounds; unit is the X12 weight unit code (L or K)."""
    if unit == 'K':
        weight = weight * LB_PER_KG
    return weight.quantize(decimal.Decimal('1'), rounding=decimal.ROUND_HALF_UP)


def date_time(s5, qualifiers):
    """First G62 of the stop with one of the qualifiers -> 'YYYY-MM-DDTHH:MM'."""
    for qualifier in qualifiers:
        date = s5.get({'BOTSID': 'S5'}, {'BOTSID': 'G62', 'G6201': qualifier, 'G6202': None})
        if date:
            time = s5.get({'BOTSID': 'S5'}, {'BOTSID': 'G62', 'G6201': qualifier, 'G6204': None})
            if time:
                return tr.datemask(date + time[:4], 'YYYYMMDDHHMM', 'YYYY-MM-DDTHH:MM')
            return tr.datemask(date, 'YYYYMMDD', 'YYYY-MM-DD')
    return None


def build_tender(inn, out, skip_note=None):
    """Write the tender. skip_note: function that says which NTE texts are not notes."""
    shipper = inn.ta_info['frompartner']
    load_id = inn.get({'BOTSID': 'ST'}, {'BOTSID': 'B2', 'B204': None})
    if not load_id:
        raise MappingFormatError('204 from %(shipper)s has no load number in B204.', {'shipper': shipper})
    # botskey: the reference shown in the web interface, and {botskey} in file names
    inn.ta_info['botskey'] = load_id
    out.ta_info['botskey'] = load_id

    purpose = inn.get({'BOTSID': 'ST'}, {'BOTSID': 'B2A', 'B2A01': None})
    put_values(out, {'BOTSID': 'tender'},
               shipper_id=shipper,
               carrier_ref=inn.ta_info['topartner'],
               test_load=inn.ta_info.get('testindicator') == 'T',
               load_id=load_id,
               purpose=PURPOSE.get(purpose, purpose),
               payment_terms=inn.get({'BOTSID': 'ST'}, {'BOTSID': 'B2', 'B206': None}),
               bol_no=inn.get({'BOTSID': 'ST'}, {'BOTSID': 'L11', 'L1102': 'BM', 'L1101': None}))

    # L11: all references of the load (the bill of lading BM also has its own field, above)
    for l11 in inn.getloop({'BOTSID': 'ST'}, {'BOTSID': 'L11'}):
        ref = out.putloop({'BOTSID': 'tender'}, {'BOTSID': 'references'})
        put_values(ref, {'BOTSID': 'references'},
                   qualifier=l11.get({'BOTSID': 'L11', 'L1102': None}),
                   value=l11.get({'BOTSID': 'L11', 'L1101': None}),
                   description=l11.get({'BOTSID': 'L11', 'L1103': None}))

    # NTE: the notes of the load in one text
    notes = []
    for nte in inn.getloop({'BOTSID': 'ST'}, {'BOTSID': 'NTE'}):
        text = nte.get({'BOTSID': 'NTE', 'NTE02': None})
        if not (skip_note and skip_note(text)):
            notes.append(text)

    # N7: equipment; L3: the rate the shipper offers (L305 has 2 implied decimals)
    eq_type = inn.get({'BOTSID': 'ST'}, {'BOTSID': 'N7', 'N711': None})
    eq_length = inn.get({'BOTSID': 'ST'}, {'BOTSID': 'N7', 'N715': None})
    put_values(out, {'BOTSID': 'tender'},
               notes=' / '.join(notes),
               equipment=EQUIPMENT.get((eq_type, eq_length)),
               trailer_no=inn.get({'BOTSID': 'ST'}, {'BOTSID': 'N7', 'N702': None}),
               offered_rate=inn.get({'BOTSID': 'ST'}, {'BOTSID': 'L3', 'L305': None}))

    # S5 loops: the stops, in sequence
    gross_weight = total_pallets = decimal.Decimal(0)
    seq = 0
    for s5 in inn.getloop({'BOTSID': 'ST'}, {'BOTSID': 'S5'}):
        seq += 1
        if int(s5.get({'BOTSID': 'S5', 'S501': None})) != seq:
            raise MappingFormatError('Load %(load)s: stop %(seq)s is out of sequence.',
                                     {'load': load_id, 'seq': seq})
        reason = s5.get({'BOTSID': 'S5', 'S502': None})
        if reason in PICKUP:
            stop_type, start, end = 'pickup', ('37', '69'), ('38',)
        elif reason in DELIVERY:
            stop_type, start, end = 'delivery', ('53', '70'), ('54',)
        else:
            raise MappingFormatError('Load %(load)s: unknown stop reason "%(reason)s" in S502.',
                                     {'load': load_id, 'reason': reason})
        if seq == 1 and stop_type != 'pickup':
            raise MappingFormatError('Load %(load)s: the first stop is not a pickup.', {'load': load_id})

        # weight and pallets: in S5, or else in AT8 (getdecimal gives 0 when there is none)
        weight = pounds(s5.getdecimal({'BOTSID': 'S5', 'S503': None})
                        or s5.getdecimal({'BOTSID': 'S5'}, {'BOTSID': 'AT8', 'AT803': None}),
                        s5.get({'BOTSID': 'S5', 'S504': None})
                        or s5.get({'BOTSID': 'S5'}, {'BOTSID': 'AT8', 'AT802': None}))
        pallets = (s5.getdecimal({'BOTSID': 'S5', 'S505': None})
                   or s5.getdecimal({'BOTSID': 'S5'}, {'BOTSID': 'AT8', 'AT804': None}))
        if stop_type == 'pickup':
            gross_weight += weight
            total_pallets += pallets

        # the place: the N1 loop of the stop (SF ship from, ST ship to)
        name = s5.get({'BOTSID': 'S5'}, {'BOTSID': 'N1', 'N102': None})
        if not name:
            raise MappingFormatError('Load %(load)s: stop %(seq)s has no N1 (name and address).',
                                     {'load': load_id, 'seq': seq})
        po_numbers = [oid.get({'BOTSID': 'OID', 'OID02': None})
                      for oid in s5.getloop({'BOTSID': 'S5'}, {'BOTSID': 'OID'})]

        stop = out.putloop({'BOTSID': 'tender'}, {'BOTSID': 'stops'})
        put_values(stop, {'BOTSID': 'stops'},
                   stop_seq=seq,
                   stop_type=stop_type,
                   name=name,
                   window_start=date_time(s5, start),
                   window_end=date_time(s5, end),
                   weight_lb=weight,
                   pallets=pallets,
                   po_numbers=','.join(po for po in po_numbers if po),
                   contact=s5.get({'BOTSID': 'S5'}, {'BOTSID': 'N1'}, {'BOTSID': 'G61', 'G6102': None}),
                   phone=s5.get({'BOTSID': 'S5'}, {'BOTSID': 'N1'},
                                        {'BOTSID': 'G61', 'G6103': 'TE', 'G6104': None}))
        put_values(stop, {'BOTSID': 'stops'}, {'BOTSID': 'address'},
                   street1=s5.get({'BOTSID': 'S5'}, {'BOTSID': 'N1'}, {'BOTSID': 'N3', 'N301': None}),
                   street2=s5.get({'BOTSID': 'S5'}, {'BOTSID': 'N1'}, {'BOTSID': 'N3', 'N302': None}),
                   city=s5.get({'BOTSID': 'S5'}, {'BOTSID': 'N1'}, {'BOTSID': 'N4', 'N401': None}),
                   state=s5.get({'BOTSID': 'S5'}, {'BOTSID': 'N1'}, {'BOTSID': 'N4', 'N402': None}),
                   zip=s5.get({'BOTSID': 'S5'}, {'BOTSID': 'N1'}, {'BOTSID': 'N4', 'N403': None}),
                   country=s5.get({'BOTSID': 'S5'}, {'BOTSID': 'N1'}, {'BOTSID': 'N4', 'N404': None}))
        # L11 references of the stop
        for l11 in s5.getloop({'BOTSID': 'S5'}, {'BOTSID': 'L11'}):
            ref = stop.putloop({'BOTSID': 'stops'}, {'BOTSID': 'stop_refs'})
            put_values(ref, {'BOTSID': 'stop_refs'},
                       qualifier=l11.get({'BOTSID': 'L11', 'L1102': None}),
                       value=l11.get({'BOTSID': 'L11', 'L1101': None}))

    put_values(out, {'BOTSID': 'tender'}, gross_weight_lb=gross_weight, total_pallets=total_pallets)
    return load_id


def main(inn, out):
    build_tender(inn, out)
    # Partner attribute attr2 = 'auto': this shipper gets an automatic 990 (accept) from Bots.
    # Returning an alt value makes Bots translate the same 204 again, with the
    # translation that has this alt (204 -> 990).
    if tr.partnerlookup(inn.ta_info['frompartner'], 'attr2', safe=None) == 'auto':
        out.put({'BOTSID': 'tender', 'auto_accepted': True})
        return 'auto990'
    return None

What it does, piece by piece:

  • put_values: in Bots, put() writes nothing at all when one of its values is None (that is how optional values are left out). With several fields in one put, one missing value would lose all of them. The helper drops the empty values first. Use it whenever one put has optional fields.
  • References (L11): every L11 under ST becomes an entry in references, with qualifier (BM bill of lading, CR customer reference, PO purchase order…). The bill of lading also gets its own field: inn.get(…, {'BOTSID': 'L11', 'L1102': 'BM', 'L1101': None}) finds the L11 whose qualifier is BM and returns its value. L11s under an S5 belong to that stop (stop_refs).
  • Stops (S5 loops): getloop goes through the stops in the order of the file. S501 must count 1, 2, 3…; S502 says what happens: LD, CL, PL load (pickup), UL, CU, PU unload (delivery). The first stop must be a pickup. Anything else stops the translation with a clear error, so the shipper can be told what is wrong.
  • Dates and times (G62): the qualifier in G6201 says which date it is. For a pickup the window starts at 37 (ship not before) or 69 (scheduled pickup) and ends at 38 (ship not later than); for a delivery 53/70 and 54. Date G6202 (YYYYMMDD) and time G6204 (HHMM) become one value 2026-10-20T08:00 with tr.datemask. A stop without an end time simply has no window_end.
  • Weights and units: the weight is in S503 with its unit in S504, or in AT803 with the unit in AT802 (ShipperB uses AT8). K is kilograms, L pounds; the TMS wants whole pounds. getdecimal gives 0 when there is no value, so a or b falls back to the second place. Total weight and pallets are the sum of the pickups.
  • Equipment (N7): equipment type N711 and length N715 (5300 = 53 feet) give the equipment code of the TMS.
  • botskey: the load number becomes the reference of the incoming and outgoing document, visible in the web interface and used in the file name tender_{botskey}_{unique}.json.
  • The automatic 990: main reads attr2 of the sender with tr.partnerlookup (safe=None: None when empty). For auto it returns 'auto990'. Bots then writes the JSON tender and translates the same 204 again, now with alt auto990; the translation with that alt makes the 990 (see Chained translations).
  1. Write the mapping of the automatic 990 usersys/mappings/x12/loadtender_x12_to_990.py. A 990 goes the other way, so it swaps sender and receiver. tr.strftime gives today's date (fixed during acceptance tests). 
    """Automatic 990 (accept) for a load tender, for shippers with partner attribute attr2 = 'auto'.

Runs as the second translation of the same 204 (alt 'auto990', returned by loadtender_x12_to_json).
"""

SCAC = 'MYCO'   # standard carrier alpha code of MyCompany


def main(inn, out):
    # the 990 goes back: sender and receiver swap
    out.ta_info['frompartner'] = inn.ta_info['topartner']
    out.ta_info['topartner'] = inn.ta_info['frompartner']
    load_id = inn.get({'BOTSID': 'ST'}, {'BOTSID': 'B2', 'B204': None})

RATE_FIELDS = {'LINEHAUL': 'rate_linehaul', 'FUEL': 'rate_fuel'}


def rate_line(text):

    words = text.split()

    # the rate lines are not notes

    for nte in inn.getloop({'BOTSID': 'ST'}, {'BOTSID': 'NTE'}):
        rate = rate_line(nte.get({'BOTSID': 'NTE', 'NTE02': None}))
        if rate:
            out.put({'BOTSID': 'tender', rate[0]: rate[1]})

  2. Write the envelope settings of ShipperB usersys/partners/x12/SHIPPERB.py. Bots reads this file for every X12 file to or from SHIPPERB and lets its syntax overrule the grammars: 
    # X12 settings for ShipperB only (overrule the envelope grammar x12.py).

    'ISA14': '1',                    # ShipperB wants to be asked for a TA1
    'add_crlfafterrecord_sep': '',   # no line break after each segment: one long line

Watch out

A translation for one partner does not always win over a translation for a group the partner is in: Bots sorts the matching translations by the partner ID as text. Here SHIPPERC comes before SHIPPERS, so ShipperC gets its own mapping. With a group called ALLSHIPPERS the group would come first and ShipperC would get the common mapping (tested). Choose IDs that sort the way you want; see How Bots chooses a translation.

Part 6: The answers of the TMS: 990 and 210

The TMS writes one JSON file per response and per invoice. These mappings show the two ways to know the shipper of a JSON file.

  1. Write the 990 mapping usersys/mappings/jsonnocheck/tenderresponse_json_to_x12.py. The input is jsonnocheck, so there are no QUERIES: the mapping reads shipper_id and carrier_ref and sets the partners of the 990. tr.partnerlookup(shipper, 'idpartner') stops with an error when the TMS names a shipper that Bots does not know. 
    """Response of the TMS to a load tender (JSON, accept or decline) -> X12 990 for the shipper."""
import textwrap

import bots.transform as tr
from bots.botslib import MappingFormatError

SCAC = 'MYCO'
ACTION = {'accept': 'A', 'decline': 'D'}


def main(inn, out):
    # jsonnocheck has no QUERIES: take the partners from the JSON here
    shipper = inn.get({'BOTSID': 'response', 'shipper_id': None})
    tr.partnerlookup(shipper, 'idpartner')     # error if the shipper is not a partner in Bots
    out.ta_info['frompartner'] = inn.get({'BOTSID': 'response', 'carrier_ref': None})
    out.ta_info['topartner'] = shipper
    load_id = inn.get({'BOTSID': 'response', 'load_id': None})
    inn.ta_info['botskey'] = out.ta_info['botskey'] = load_id

    decision = inn.get({'BOTSID': 'response', 'decision': None})
    if decision not in ACTION:
        raise MappingFormatError('Load %(load)s: decision must be accept or decline, not "%(decision)s".',
                                 {'load': load_id, 'decision': decision})
    # decided_at is YYYY-MM-DDTHH:MM:SS; B103 wants YYYYMMDD
    decided = inn.get({'BOTSID': 'response', 'decided_at': None})[:10]

    st02 = out.ta_info['reference'].zfill(4)
    out.put({'BOTSID': 'ST', 'ST01': '990', 'ST02': st02})
    out.put({'BOTSID': 'ST'}, {'BOTSID': 'B1',
                               'B101': SCAC,
                               'B102': load_id,
                               'B103': tr.datemask(decided, 'YYYY-MM-DD', 'YYYYMMDD'),
                               'B104': ACTION[decision]})
    # accepted: the PRO number of MyCompany as carrier reference (N9*CN).
    # No pro_no in the JSON: get() gives None, and a put with a None value writes nothing.
    out.put({'BOTSID': 'ST'}, {'BOTSID': 'N9', 'N901': 'CN',
                               'N902': inn.get({'BOTSID': 'response', 'pro_no': None})})
    # declined: the reason, in K1 (K101 and K102, each at most 30 characters)
    reason = inn.get({'BOTSID': 'response', 'reason': None})
    if decision == 'decline' and reason:
        parts = textwrap.wrap(reason, 30)
        out.put({'BOTSID': 'ST'}, {'BOTSID': 'K1', 'K101': parts[0]})
        if len(parts) > 1:
            out.put({'BOTSID': 'ST'}, {'BOTSID': 'K1', 'K102': parts[1]})
    out.put({'BOTSID': 'ST'}, {'BOTSID': 'SE', 'SE01': out.getcount() + 1, 'SE02': st02})

The mapping checks that the charges add up to the total, takes the weight unit from attr1, and the charge codes from the code list. 
    """Freight invoice of the TMS (JSON) -> X12 210 for the shipper.

Partner differences, without a mapping per shipper:
- partner attribute attr1: the weight unit the shipper wants on the 210 (L pounds, K kilograms);
- code list charge_code: the X12 code per charge type, and per shipper where it differs
  (left code SHIPPERB:detention wins over detention).
"""
import decimal

import bots.transform as tr
from bots.botslib import MappingFormatError

SCAC = 'MYCO'
KG_PER_LB = decimal.Decimal('0.45359237')


def charge_code(shipper, charge_type):
    """X12 charge code (L108): first the code for this shipper, else the general one."""
    return (tr.ccode('charge_code', shipper + ':' + charge_type, safe=None)
            or tr.ccode('charge_code', charge_type))


def weight_in(weight_lb, unit):
    if unit == 'K':
        weight_lb = weight_lb * KG_PER_LB
    return weight_lb.quantize(decimal.Decimal('1'), rounding=decimal.ROUND_HALF_UP)


def ymd(value):
    """YYYY-MM-DD -> YYYYMMDD"""
    return tr.datemask(value, 'YYYY-MM-DD', 'YYYYMMDD')


def main(inn, out):
    # frompartner and topartner come from the QUERIES of the grammar (carrier_ref, shipper_id)
    shipper = inn.ta_info['topartner']
    unit = tr.partnerlookup(shipper, 'attr1', safe=None) or 'L'
    inv_number = inn.get({'BOTSID': 'invoice', 'inv_number': None})
    out.ta_info['botskey'] = inv_number

    # the charges must add up to the total
    total = inn.getdecimal({'BOTSID': 'invoice', 'total_amount': None})
    charges = list(inn.getloop({'BOTSID': 'invoice'}, {'BOTSID': 'charges'}))
    sum_charges = sum(c.getdecimal({'BOTSID': 'charges', 'amount': None}) for c in charges)
    if sum_charges != total:
        raise MappingFormatError('Invoice %(inv)s: charges add up to %(sum)s, total_amount is %(total)s.',
                                 {'inv': inv_number, 'sum': sum_charges, 'total': total})

    st02 = out.ta_info['reference'].zfill(4)
    out.put({'BOTSID': 'ST', 'ST01': '210', 'ST02': st02})
    out.put({'BOTSID': 'ST'}, {'BOTSID': 'B3',
                               'B302': inv_number,
                               'B303': inn.get({'BOTSID': 'invoice', 'load_id': None}),
                               'B304': inn.get({'BOTSID': 'invoice', 'terms': None}) or 'PP',
                               'B306': ymd(inn.get({'BOTSID': 'invoice', 'invoiced_on': None})),
                               'B307': total,
                               'B309': ymd(inn.get({'BOTSID': 'invoice', 'delivered_on': None})),
                               'B310': '035',
                               'B311': SCAC})
    out.put({'BOTSID': 'ST'}, {'BOTSID': 'C3',
                               'C301': inn.get({'BOTSID': 'invoice', 'currency': None}) or 'USD'})
    # references: bill of lading, PRO number of MyCompany
    for qualifier, field in (('BM', 'bol_no'), ('CN', 'pro_no')):
        value = inn.get({'BOTSID': 'invoice', field: None})
        if value:
            n9 = out.putloop({'BOTSID': 'ST'}, {'BOTSID': 'N9'})
            n9.put({'BOTSID': 'N9', 'N901': qualifier, 'N902': value})
    # bill-to party
    billto = inn.get({'BOTSID': 'invoice'}, {'BOTSID': 'billto', 'name': None})
    if billto:
        n1 = out.putloop({'BOTSID': 'ST'}, {'BOTSID': 'N1'})
        n1.put({'BOTSID': 'N1', 'N101': 'BT', 'N102': billto})
        n1.put({'BOTSID': 'N1'}, {'BOTSID': 'N3',
                                  'N301': inn.get({'BOTSID': 'invoice'}, {'BOTSID': 'billto', 'street1': None})})
        n1.put({'BOTSID': 'N1'}, {'BOTSID': 'N4',
                                  'N401': inn.get({'BOTSID': 'invoice'}, {'BOTSID': 'billto', 'city': None}),
                                  'N402': inn.get({'BOTSID': 'invoice'}, {'BOTSID': 'billto', 'state': None}),
                                  'N403': inn.get({'BOTSID': 'invoice'}, {'BOTSID': 'billto', 'zip': None})})

    # weight and pallets, in the unit this shipper wants
    weight = weight_in(inn.getdecimal({'BOTSID': 'invoice', 'gross_weight_lb': None}), unit)
    pallets = inn.get({'BOTSID': 'invoice', 'total_pallets': None})

    # one LX loop per charge
    for number, charge in enumerate(charges, start=1):
        charge_type = charge.get({'BOTSID': 'charges', 'charge_type': None})
        lx = out.putloop({'BOTSID': 'ST'}, {'BOTSID': 'LX'})
        lx.put({'BOTSID': 'LX', 'LX01': number})
        lx.put({'BOTSID': 'LX'}, {'BOTSID': 'L5', 'L501': number,
                                  'L502': tr.ccode('charge_code', charge_type, field='attr1')})
        if number == 1:
            # weight and pallets once, on the first line
            lx.put({'BOTSID': 'LX'}, {'BOTSID': 'L0', 'L001': number, 'L004': weight, 'L005': 'G',
                                      'L008': pallets, 'L009': 'PLT', 'L011': unit})
        lx.put({'BOTSID': 'LX'}, {'BOTSID': 'L1', 'L101': number,
                                  'L104': charge.get({'BOTSID': 'charges', 'amount': None}),
                                  'L108': charge_code(shipper, charge_type)})

    out.put({'BOTSID': 'ST'}, {'BOTSID': 'L3', 'L301': weight, 'L302': 'G', 'L305': total,
                               'L311': pallets, 'L312': unit})
    out.put({'BOTSID': 'ST'}, {'BOTSID': 'SE', 'SE01': out.getcount() + 1, 'SE02': st02})
    • Amounts are written with their decimal point (1850.00); because B307, L104 and L305 have format N2, Bots writes them with implied decimals: 185000.
    • tr.ccode('charge_code', charge_type) without safe stops with an error when a charge type is not in the list: better than a 210 with an empty code.

Variations

Adding ShipperD

With this design a new shipper that needs nothing special takes no new files:

  1. Partner SHIPPERD in group SHIPPERS, with attr1 and attr2.
  2. Channels shipperd_in and shipperd_out.
  3. Route parts: loadtenders_in 13 (in) and 33 (out, Topartner tochannel SHIPPERD); tms_to_shippers 33.
  4. Only if needed: rows SHIPPERD:… in the code list, usersys/partners/x12/SHIPPERD.py, a translation with frompartner SHIPPERD and a small mapping.
  5. Test with the shipper's test files (ISA15 T) and tell the TMS team that test_load is true.

One shared outgoing channel instead of one per shipper

When all shippers collect from the same server, each in its own folder, one channel can serve them all: Filename {topartner}/{messagetype}_{unique}.edi on a channel shippers_out with path botssys/outfile/shippers, and one route part without Topartner tochannel instead of parts 30 to 32 (tested: the files land in SHIPPERA/, SHIPPERB/, SHIPPERC/; the sub-folders must exist). Fewer channels, but one login for all shippers and no way to stop one shipper alone. With separate servers per shipper, as is usual, keep one channel per shipper.

One route per shipper

Many installations grow one route per shipper (shippera_in, shippera_out…). It is easy to understand and lets you switch one shipper off by making its route inactive, but every change must be made in every route, and the list of routes grows with every shipper. The design of this page keeps one route per flow; to switch one shipper off, make its incoming route part inactive.
